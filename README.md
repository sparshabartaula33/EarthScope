
# EarthScope

### Exploring Earth Through NASA Data

EarthScope is a web-based platform that helps users explore changes in Earth's environmental variables using NASA Earth science data.

## Objectives

- Explore environmental variables across different regions.
- Visualize changes over time.
- Identify increasing and decreasing trends.
- Analyze the magnitude and statistical significance of changes.
- Make Earth science data easier to understand.

## Project Structure

- frontend/ - User interface
- backend/ - Data processing and analysis
- docs/ - Project documentation
